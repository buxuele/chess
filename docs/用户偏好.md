# 用户偏好

本文档汇总本项目持续改进过程中用户表达的喜好与决策，作为后续开发的基准。

## 界面形态

1. 极简主界面：主界面只放 棋谱 与 设置 两颗文字入口，其余配置项全部收进设置面板，不允许在主界面散落多个控件。
2. 设置面板统一收纳：模式、执子、难度、主题颜色、音效等选项集中在一个弹窗内，面板以 完成 按钮关闭。
3. 棋谱按需打开：不占常驻空间，顶栏 棋谱 按钮带步数，点开用抽屉展示，桌面右侧、手机底部。
4. 开始新对局只保留一颗常驻按钮，固定右下角，一键直达最终目的。
5. 无副标题、无口号卡片，页面顶部只保留标题与状态。
6. 棋盘单轴居中：不设右侧常驻栏，设置与棋谱收进顶栏，棋盘与顶栏左右边缘对齐。
7. 玩家条只保留行棋方圆点、名字、执子难度与子力差，不显示王冠色块、玩家字样与计时。
8. 将军与思考中只在对应玩家条内以短标签出现，对局结束由结算卡表达，正常走棋依靠行棋方圆点与名字高亮。

## 视觉偏好

1. 主题色限定两选：西瓜红 #fc0377 与橄榄绿 #9adb37，设置面板内以 主题颜色 分段切换，当前生效色落在按钮、开关、提示等强调元素上。
2. 将军提示用淡红：被将军的王所在格必须整格铺淡红色并伴随红光呼吸动画，右上徽章同步亮 将军 状态。
3. 棋子使用经典 cburnett 风格，避免卡通化自绘。

## 动效节奏

1. AI 落子要慢：AI 走子滑动时长 0.34 秒，人走子 0.16 秒，快慢分级，突出对局节奏感。
2. 动画时长如需再调整，优先以体感为准在 ui.js 的 pendingAnim 常量处修改。
3. 按钮不做悬停位移或上浮，只保留颜色变化与 focus-visible 描边。

## 交互习惯

1. 保留全部键盘快捷键：U 悔棋、N 新对局、F 翻转、H 提示、R 认输、S 设置。
2. 高级功能可以裁掉界面入口，但不能裁掉能力本身，幸存能力全部走快捷键并写进文档。
3. 一切操作障碍优先由 agent 自行排查与修复，用户只负责验收结果。
4. 棋谱抽屉支持关闭按钮、遮罩点击与 Esc 三种退出方式，关闭后焦点回到入口。

## 文档与交付

1. 全中文回复与文档，禁 emoji，禁花哨排版。
2. 重要需求改动必须补进 开发记录.md，踩坑过程如实记录，时间倒序。
3. 验证必须用无头浏览器真开页面，截图存入 效果图 目录，不许只看命令行返回码。
