# 用户偏好

本文档汇总本项目持续改进过程中用户表达的喜好与决策，作为后续开发的基准。

## 界面形态

1. 极简主界面：主界面只放 设置 与 新对局 两颗文字按钮，固定在右上角，窄屏时排在内容区上方右对齐。
2. 设置抽屉统一收纳：模式、执子、难度、主题颜色、移动速度、音效六项集中在抽屉内，以 关闭 按钮退出。
3. 不设页面标题、玩家名字、状态标签、坐标标注与棋谱入口。
4. 不显示被吃棋子、子力差、名字、圆点与计时。
5. 对局结束在宽屏右侧显示结算卡、窄屏底部浮层显示，写明胜负与原因，棋盘不位移。
6. 主界面只有棋盘，桌面下棋盘高度等于视口高度，上下无缝隙。

## 视觉偏好

1. 主题色限定两选：西瓜红 #fc0377 与橄榄绿 #9adb37，设置抽屉内以 主题颜色 分段切换，当前生效色落在按钮、开关、提示等强调元素上。
2. 将军提示用淡红：被将军的王所在格整格铺淡红色，不做闪烁或呼吸动画。
3. 棋子使用经典 cburnett 风格，避免卡通化自绘。
4. 棋盘不要外框、圆角与内阴影，四边直接贴合页面背景。
5. 背景可在设置里选，默认 #cfd3cd，深色背景自动切浅色文字。
6. 结算卡宽 230 像素、标题 24 号字、原因 13 号字；宽屏在右侧，窄屏在底部，不推动棋盘。
7. 结算文案带调侃，按难度与胜负切换，按钮写 不服再来，目的是激发再来一局。

## 动效节奏

1. 走子滑行按距离计算：每格 0.1 秒、0.15 秒、0.2 秒三档，默认慢档，距离越远滑行越久；拖拽落子直接到位；系统开启减弱动态效果时滑行仍然保留。
2. 动画时长如需再调整，优先以体感为准在 src/game/store.js 的 SPEED_CELL 常量处修改。
3. 点再来一局时棋子从旧位置滑回初始位置，不做瞬间闪现。
4. 按钮不做悬停位移或上浮，只保留颜色变化与 focus-visible 描边。

## 交互习惯

1. 保留全部键盘快捷键：U 悔棋、N 新对局、F 翻转、H 提示、R 认输、S 设置。
2. 高级功能可以裁掉界面入口，但不能裁掉能力本身，幸存能力全部走快捷键并写进文档。
3. 一切操作障碍优先由 agent 自行排查与修复，用户只负责验收结果。
4. 选中后点空白格或对方棋子，蓝色高亮必须保持；只有点合法目标格才落子，点另一枚己方棋子才换选。

## 运行与进程

1. 严禁项目自己启动：不自动打开浏览器，不自动弹出窗口，自检与截图模式不得抢焦点、不得置顶、不得出现在 Dock。
2. 只有用户主动运行 just_run.sh 或 just_run.bat 时才允许出现窗口或服务；其余验证一律用无头实例，结束后按进程号清理。
3. 同一项目只允许一个会话改动文件，发现并发写入先定位并结束，不允许互相覆盖。

## 文档与交付

1. 全中文回复与文档，禁 emoji，禁花哨排版。
2. 重要需求改动必须补进 开发记录.md，踩坑过程如实记录，时间倒序。
3. 验证必须用无头浏览器真开页面，截图存入 效果图 目录，不许只看命令行返回码。
